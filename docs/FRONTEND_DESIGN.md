# 前端设计约定

界面在 2026-11-15 改版后的现行约定：简洁、安静、好读，颜色只做点缀。改界面时照此执行；设计变量集中在 `frontend/src/styles.css` 顶部，不要在别处写死颜色和字号。

| 项 | 约定 |
|---|---|
| 底色 | 暖白 `#F3EFEA`；右上一团很淡的暖橙柔光，不用图片 |
| 文字 | 正文深灰 `#2A2724`；次要文字 `#6B655F`；不使用更浅的灰字 |
| 点缀色 | 橙 `#F0894A`，只用于小圆点、进度条、柔光和数字徽标底色 `#FBE3D3`；不用于正文文字，不做大面积色块 |
| 面板 | 浅色面板，边框几乎不可见，大圆角；只给需要成组的内容用，列表行用细分隔线而不是每条一张卡片 |
| 字体 | 系统字体（中文苹方等），通过 `--font` 变量统一；大标题用细体；没有引入外部字体 |
| 字号 | 13 / 14 / 15 / 16 / 20 / 36 / 52px；正文 15–16px，最小 13px |
| 分类与课程配色 | 邮件类别标签用中性色，只有个别用浅橙；课程按代码固定配色，颜色只用在卡片左侧细条 |
| 不要出现 | 全大写英文小标题、标语式页脚、黑色大卡片、按钮后的装饰箭头、所有内容都套卡片 |
| 质量底线 | 手机 375px 可用、键盘焦点可见、遵守“减少动态效果”、文字对比度 ≥ 4.5（≥ 24px 的大字 ≥ 3） |

## 页面结构

- 导航：桌面顶部 / 手机底部 5 项（主页 / 日程 / 邮件 / 课堂翻译 / HKU 指南），当前项下方一个橙色小点；“邮件”旁显示新邮件通知数，为 0 时不显示。
- 子页面在页面内切换（邮件：统一收件箱 / 起草邮件 / 邮箱管理；日程：日程 / 课表；课堂翻译：实时翻译 / 课程记录；HKU 指南 3 类），保留 `#/inbox` 这类地址和浏览器前进后退。
- 账号与退出在右上角头像菜单。
- 每页统一页头：标题、一句用途、右侧主要操作；空状态给出下一步操作；加载用骨架屏。
- 标志为衬线字“HK Mate”加暖橙光点（`Brand.jsx`）。

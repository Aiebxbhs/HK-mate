# 0002：独立本地邮件摘要模型

日期：2026-11-12。状态：用户已授权本地部署，并使用最近五封真实收到的邮件测试。

选择原生 Ollama 0.40.16 + `qwen3:4b-instruct-2507-q4_K_M`，通过固定 `127.0.0.1:11434/api/chat` 调用。模型与 Web Python 虚拟环境独立，使用 Mac Metal GPU，不新增通用 Agent 框架、队列或数据库表。运行包已核对官方发布摘要；权重、运行程序和私人结果不进入 Git。

选择理由：当前只需要纯文本中文摘要、结构化输出和较低本机资源消耗。与在 Web 环境安装 PyTorch/Transformers 相比，独立推理进程可避免依赖耦合；本阶段不使用云模型处理邮件，也不优先选择增加多模态复杂度的方案。

Agent 仅组合系统提示词、编号原文、模型调用与 Pydantic 校验，无任何工具。首轮自由抄写引用出现改写问题，因此 v2 改为模型选择原文行号、程序直接提取引用；引用正确不代表结论必然正确，语义仍需人工核对。日期必须在对应引用中逐字出现，不自动推算。

本阶段提供手动五封测试及私有报告；自动新邮件检测、去重、摘要加密持久化和页面展示另行实施。现有登录和 Gmail 接入不依赖模型服务可用性。完整运行步骤及测试边界见 [本地模型部署](../LOCAL_MODEL.md)。

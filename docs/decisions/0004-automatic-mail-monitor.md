# 0004：本地后台新邮件检测与自动摘要

日期：2026-11-12。用户明确要求首页自动接收真实新邮件通知并生成摘要，替换演示数据。

采用 Gmail 历史游标轮询及本地双线程：检测与摘要分离；初次仅补查最近一小时，以免遗漏刚发的测试邮件。新增加密游标、持久化去重通知及摘要状态，归属当前邮箱用户，复用现有密钥与模型锁。摘要与类别在一次本地调用中生成，保持用户现有摘要提示词，并附加类别枚举及日期原文约束。

不引入消息队列、Pub/Sub、公网推送服务或模型云调用；本阶段单后端进程运行。页面定期获取持久化结果，忽略不影响 Gmail。未来多进程部署需要分布式任务领取/租约，不能直接扩展 worker 数量。日程保存已于 2026-11-13 接入：复用“我的日程”的空白添加表单，由用户自行填写后保存，不从邮件预填。详见 [自动邮件处理](../AUTO_MAIL.md)。

# 课程实时翻译与课程记录

上课时把老师的英文讲话实时转成中英双语字幕，可同时记录带时间点的笔记；下课后由本机 AI 生成中文摘要，用户自己决定是否保存到“课程记录”。识别、翻译和摘要全部在本机完成，不上传、不保存录音。

本文描述当前实现（2026-11-14）。开发过程与决策见 [开发记录](LECTURE_TRANSLATION_PLAN.md)，模型选型和延迟实测见 [实测报告](LECTURE_BENCH.md)。

## 1. 使用说明

### 准备

- 安装语音依赖：`uv sync --group speech`。
- Whisper 模型 `mlx-community/whisper-large-v3-turbo` 需已下载到 `private-data/models/hf`（方法见 [实测报告](LECTURE_BENCH.md) 第 6 节）；运行时只从本地加载，不联网下载。
- Ollama 与 Qwen3 4B 需在运行（`bash scripts/ollama-serve.sh`）。
- **用 Chrome 或 Safari 打开** `http://localhost:5173` 或 `http://127.0.0.1:5173`。Claude 应用内置浏览器禁止网页使用麦克风，无法录音；VS Code 集成浏览器也可能受限。
- 录音前须获得授课老师和学校允许，并遵守课程关于录音或转写的规定。

### 上课

1. 菜单“课程翻译 → 实时翻译”，点“开始课程”开始计时。
2. 点“开始录音”。首次录音会请你确认已获允许（每个账号在本机只问一次），浏览器还会请求麦克风权限。
3. 老师说话时，正在说的这句以灰色斜体实时显示英文（“正在听…”）；这句结束后换成正式字幕，中文随后出现。
4. 可随时“暂停录音 / 继续录音”，暂停期间不计入录音时长。
5. 右侧笔记栏输入后按回车添加，自动记录课程内时间；可编辑、删除、标为重点。不录音也可以只记笔记。
6. 上课中的字幕和笔记暂存在本机浏览器（按账号），刷新或意外关闭页面后会自动恢复。

### 下课与保存

1. 点“结束课程”，确认“确定要结束课程吗？”（选“继续上课”可返回）。
2. 进入保存表单，顶部提示“AI 课程摘要正在生成，请稍等”，期间可以先填写信息：
   - 课程名称（必填，可从已有课程名称中选择，同名课程在“课程记录”中归为一组）；
   - 其他信息（可选，如周次、本节主题）。
3. 摘要生成后显示预览，选择保存哪些内容：
   - **AI 摘要与重点**：生成成功后默认勾选，可“重新生成”；
   - **我的笔记**：默认勾选；
   - **逐句转写与译文**：默认不勾选。
4. 摘要生成失败时会说明原因并可“重试”，也可以只保存笔记。
5. “保存到课程记录”或“不保存，丢弃”（丢弃需再次确认）。保存或丢弃后，本机暂存清除。

### 课程记录

菜单“课程翻译 → 课程记录”：按课程名称分组，加粗显示课程名，每节课显示日期（如 11.14）、时长、笔记数和是否有 AI 摘要。打开一节课可以：

- 查看 AI 摘要（概览、作业/考试/截止/通知提醒、重点；每条附课程内时间，可展开查看老师的英文原话）、笔记和逐句转写；
- 编辑课程名称、其他信息和笔记；
- 删除（需确认）；
- 导出 Markdown 文件。

记录数量不设上限，按账号隔离，其他账号看不到。

## 2. 工作原理

```
浏览器麦克风 ─16 kHz PCM16，每 100 ms 一帧─▶ WebSocket /api/v1/lecture/stream
   ─▶ 能量 VAD 切句 ─▶ mlx-whisper（英文）─▶ Qwen3 4B 翻译（中文）─▶ 双语字幕
         │                    ▲
         └─ 说话中每约 1 秒 ──┘（临时英文，灰色显示）

结束课程 ─▶ POST /api/v1/lecture-summaries ─▶ 分段提取（英文笔记）─▶ 汇总（中文）─▶ 预览
```

### 实时字幕

- **采集**：AudioWorklet（`frontend/public/pcm-capture-worklet.js`）在 16 kHz AudioContext 中转为 PCM16；开启回声消除、降噪和自动增益。暂停或离开页面时释放麦克风。
- **切句**：能量 VAD，阈值随环境噪声自适应（上限 0.04，避免连续讲话时“失聪”）。短句需 0.5 秒停顿；超过 3 秒后 0.18 秒停顿即可断句；满 7 秒时在最近 2 秒最安静处切开，余下部分并入下一句。
- **识别**：mlx-whisper large-v3-turbo，固定英文，关闭 `condition_on_previous_text`（开启时会重复循环），以前文（≤ 200 字符）作提示，过滤静音上的常见幻觉（如 “Thank you.”）。
- **临时英文**：说话过程中约每 1 秒识别一次未结束的句子并灰色显示，不保存；完成的句子优先处理，临时识别只保留最新请求。
- **翻译**：Qwen3 4B，附前两句作上下文，保留课程术语和专有名词的英文。识别与翻译是两个并行任务。
- **模型共享**：与邮件功能共用一个 Qwen 实例和 16K 上下文（避免重载）。录音期间后台邮件摘要暂停排队；若模型被占用超过 30 秒，该句跳过翻译，不阻塞字幕。
- **实测延迟**（TED 真人演讲，实时推流，中位数）：开口到出现英文约 1.3 秒，到出现中文约 5.3 秒（P90 7.4 秒）。中文需等一句说完，这是逐句翻译的固有延迟。

### 课后摘要

- 触发：结束课程且最后一句字幕处理完后自动生成；没有录音字幕或少于 40 个英文词时不生成。
- **分段提取**：字幕按约 2500 词分段，每段输出英文笔记——先列课程安排（作业、考试与考试重点、截止、提交方式、阅读、答疑时间），再列最多 12 个知识点，每条引用句子编号。
- **汇总**：用中文写 2–4 句概览、每段的重点（JSON schema 规定每段至少一条，保证覆盖整节课，全课合计不超过约 12 条）和课程安排提醒。
- **证据由程序负责**：模型只引用编号；程序把编号换成课程内时间和最多两句英文原话，丢弃引用无效的条目。概览、重点、提醒若不是中文则重试；格式不合格重试一次。
- **笔记只作参考**：重点笔记优先，最多 40 条；提示词要求不得把学生笔记写成老师所讲。
- **防注入**：字幕和笔记都作为数据传入，提示词要求忽略其中的指令；模型没有任何工具或写操作。
- 用时：3 分钟课约 40 秒；约 1.2–1.4 万词的 90 分钟课预计约 3 分钟。每次模型调用单独取模型锁，期间邮件功能可穿插执行。

## 3. 数据与隐私

| 内容 | 处理方式 |
|---|---|
| 录音 | 只在后端内存中切句识别，识别完即丢弃；不落库、不写日志、不上传 |
| 字幕、笔记（上课中） | 只暂存在本机浏览器 localStorage（按账号），保存或丢弃后清除 |
| 识别文字与译文 | 不写日志；只有勾选“逐句转写与译文”时才随记录保存 |
| AI 摘要 | 生成接口只返回不落库；勾选后随记录保存 |
| 课程记录 | `lecture_records` 表，按 `user_id` 隔离；课程名称（及旧记录的课程编号）明文以便分组，其余（其他信息、笔记、摘要、转写，以及旧记录中的授课老师）用本机 Fernet 密钥加密保存 |

## 4. 接口

均需登录；HTTP 写请求受 Origin 与 CSRF 保护，WebSocket 在握手后单独校验 Origin 与登录会话。

| 接口 | 说明 |
|---|---|
| `WS /api/v1/lecture/stream` | 二进制帧：16 kHz 单声道 PCM16（每帧 ≤ 64 KB，单段最长 4 小时）；文本帧 `{"type":"pause"}` / `{"type":"stop"}`。服务端发送 `status`（loading / listening / stopped）、`partial`（`offset`、`en`；`en` 为 null 表示清除）、`caption`（`id`、`offset`、`duration`、`en`）、`translation`（`id`、`zh` 或 null）、`error`（`code`、`message`）。每个账号同时只允许一个录音流 |
| `POST /api/v1/lecture-summaries` | 请求 `{"lines":[{"at_seconds","en"}], "notes":[...]}`（≤ 20000 句、≤ 500 条笔记）；返回摘要（`version`、`overview`、`key_points`、`reminders`，每条含 `at_seconds` 与 `quotes`）。不落库 |
| `GET /api/v1/lecture-records` | 记录列表（不含笔记、摘要等私密内容，只给 `has_summary` 等统计） |
| `POST /api/v1/lecture-records` | 保存一节课：`course_name`、`extra_info`、`started_at`、`ended_at`、`recorded_seconds`、`notes`，可选 `summary`（版本须为 `lecture-summary-v1`）、`transcript`；`course_code`、`instructor` 仍可选接受，界面已不再填写 |
| `GET / PATCH / DELETE /api/v1/lecture-records/{id}` | 查看、修改（课程信息与笔记）、删除 |

## 5. 已知限制

- 只支持英文讲课、英译中；只在 Apple 芯片 Mac 上运行（mlx）。
- 只做过合成课程与 TED 演讲测试，未在真实课室（远场收音、混响、学生提问）系统测试。
- 中文字幕比讲话晚约一句（中位数约 5 秒）；句子切短后偶尔一句被拆成两段翻译，译文可能补出原句没有的主语。
- 摘要由 4B 本地模型生成，可能遗漏内容或加入少量原文没有的说法；时间点和原话由程序提取，可用于核对。
- 录音期间后台邮件摘要会暂停，下课后继续。

## 6. 常见问题

> 2026-11-14 修复：此前全局 16 KB 请求体上限会让较长课程的摘要生成和带转写的保存失败（“请求内容过大”），现课程摘要与课程记录接口上限为 4 MB。


| 现象 | 处理 |
|---|---|
| 提示麦克风被禁止（“blocked in the Browser pane”） | 在 Chrome 或 Safari 中打开页面，不要用 Claude 应用内置浏览器 |
| 浏览器没有获得麦克风权限 | 地址栏网站设置中允许麦克风；macOS“系统设置 → 隐私与安全性 → 麦克风”中勾选浏览器后重启浏览器 |
| 语音识别组件未安装 / 未找到 Whisper 模型 | 运行 `uv sync --group speech`，按实测报告第 6 节下载模型 |
| 字幕有英文但中文“没有翻译成功” | 确认 Ollama 在运行；模型被其他请求占用超过 30 秒时也会跳过该句 |
| 摘要生成失败 | 按提示检查 Ollama；可点“重试”，或只保存笔记 |
| 这个账号已经在另一个页面录音 | 关闭或暂停另一页面的录音 |

```bash
bash scripts/check.sh                                              # 全部单元测试（模拟模型）
.venv/bin/python scripts/lecture-stream-test.py                    # 合成课程实时推流（真实模型）
.venv/bin/python scripts/lecture-stream-test.py --ted 0 --seconds 180   # TED 真人演讲延迟
.venv/bin/python scripts/test-lecture-summary.py --source synthetic     # 课后摘要（真实模型）
```

后三个需要 `uv sync --group speech --group bench`、本地模型和运行中的 Ollama；使用临时数据库和合成账号，不访问真实课程数据。

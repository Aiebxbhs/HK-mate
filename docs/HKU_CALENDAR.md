# HKU 课表导入

已按用户授权导入 46 条 HKU 课程，关联到明确的所属账号，替换首页示例日程。原 ICS 位于 Git 忽略的 `private-data/calendar-imports/`，权限 600；不将订阅令牌写入代码、数据库或日志。

“我的日程”以列表按日期分组显示接下来 100 天的课程和手动日程（香港时间、地点、来源），可添加和删除。首页“接下来 5 天”从同一份数据按天展示课程、手动日程和截止事项（开始时间升序）；其他账号不能访问。

首页标题在课程代码与班别后补充课程全名。名称从原 ICS 说明中提取，只有说明中的课程代码与标题一致时才使用，不猜测缺失名称；读取接口通过 `course_name` 字段提供，数据库原始标题与说明保持不变。地点文字已放大以便阅读。

当前是一次性快照导入（命令行导入本地文件，或在“我的课表”页面粘贴链接），不保存订阅链接，不自动同步学校更新，不向学校写回修改。手动日程通过 `POST /api/v1/calendar/events`（标题、日期、起止时间、地点；仅限同一天，按香港时间保存）创建，`DELETE /api/v1/calendar/events/{id}` 删除，均只作用于当前登录账号。手动日程以 source=manual 保存，重新导入 HKU 课表只替换 hku 来源，不会覆盖手动日程；被删除的 HKU 课程在重新导入后会恢复。日程类型 `kind` 为 event（有起止时间）或 deadline（单一截止时间，starts_at 与 ends_at 相同，查询时午夜截止归属当天）；`completed_at` 记录完成时间，`POST /api/v1/calendar/events/{id}/completion` 以 `{"completed": true/false}` 标记或撤销，HKU 课程也可标记，重新导入课表不会清除。截止进度条由前端按剩余时间计算，不写入数据库。2026-11-13 迁移前已在线备份数据库至 `private-data/backups/`，迁移已在副本上验证可回退。编辑（2026-11-15）：`PUT /api/v1/calendar/events/{id}` 接受与添加相同的字段（类型、标题、日期、起止或截止时间、地点；省略 `description` 时保留原值），只能编辑当前账号自己添加的日程（source=manual），完成状态保持不变；他人的日程返回 404，HKU 课程返回 400 `CALENDAR_EVENT_READ_ONLY`（课程来自学校课表，重新导入会覆盖，只能删除或标记完成）。前端在“我的日程”中自己添加的日程旁显示“编辑”，点击后在原位置打开预填当前内容（香港时间）的同一表单，保存后显示“日程已修改。”。

## 我的课表（2026-11-15）

菜单“我的日程 → 我的课表”只显示 HKU 来源的课程，不含手动日程。仿 HKU 门户课表，整学期是一个可上下滚动的长日历（2026-11-15 按用户要求取消按 4 周翻页）：每行一周、周一至周日，从第一节课所在周到最后一节课或考试所在周（最多 60 周），周几表头滚动时固定在顶部；打开时定位到本周，学期内显示“回到本周”。课程卡片显示课程代码与班别、时间、地点，同一课程固定一种颜色，考试（标题含 Examination）用虚线框和“考试”标签；点卡片在该周下方展开详情（含课程全名）。日程接口每次最多 100 天，前端按 98 天分段请求后合并。手机上改为只列出有课的日期。

页面还通过 `GET /api/v1/calendar/courses`（需登录，只返回当前账号）读取按课程代码汇总的信息（课程全名、每周上课时段、首末日期、次数、考试），用于判断是否已导入、固定课程颜色、“学期第一周”和卡片详情中的课程全名。2026-11-15 按用户要求去掉了页面上的“课程一览”模块，接口保留。

## 在页面中用链接导入（2026-11-15）

第一次打开“我的课表”且没有 HKU 课程时，页面显示链接输入框和 4 步图文教程（图片在 `frontend/public/guide/timetable-help/`）：HKU Portal → SIS → HKU Event Calendar (Timetable) → Subscription Setting，打开 Enable Internet Calendar、选 One Year、COPY 链接并 SAVE。已有课程时，工具栏“重新导入”打开同一表单，教程默认折叠。

`POST /api/v1/calendar/import`（需登录，受 Origin 与 CSRF 保护，请求体 `{"url": "..."}`）由后端下载一次订阅内容并替换当前账号的 HKU 课程，返回 `{"imported": n, "skipped_all_day": m}`。限制：只接受 `https://` 或 `webcal://`（按 https 下载）开头、主机为 `hku.hk` 或其子域、默认端口、不含用户名密码的链接；重定向只在 hku.hk 内跟随（最多 3 次）；超时 20 秒，内容上限 5 MB。链接不保存、不写日志、不出现在错误信息中；下载或解析失败时不修改已有课程。订阅中的全天事件（如 University Holiday）不是课程，链接导入时跳过并在结果中计数；命令行导入本地文件时仍拒绝全天事件。

2026-11-15 按用户要求清空了全部 HKU 课程（共 97 条，含本地测试账号的合成数据），以便用户在页面中实测导入；清空前备份到 `private-data/backups/hkumate-before-clear-hku-timetable-20261115.sqlite3`。

## 存储和接口

`calendar_events` 表保存所属用户、来源、原始 UID、标题、地点、说明、UTC 起止时间及导入时间；唯一键为用户 + 来源 + UID。`icalendar` 负责折行、转义和时区解析。当前支持带明确时区的独立起止事件，遇到重复规则、全天或缺少明确时间等未支持格式会拒绝整次导入，避免静默漏课。

同一用户重新导入时按 UID 更新，保留已有事件 ID，只移除该用户 HKU 来源中缺失的条目，不影响其他用户与来源；整个更新在单个事务中完成。

`GET /api/v1/calendar/events?start_date=2026-11-01&end_date=2026-12-01` 需要登录，身份由会话确定。日期按香港时间解释，结束日期不包含，返回与区间重叠的所有课程；查询范围为 1–100 天，最多 1000 条，响应包含当前用户导入总数。

## 重新导入

将新的 ICS 下载到私有目录，导入前用 SQLite backup API 备份数据库。本次首次导入前已创建备份。

```bash
.venv/bin/alembic upgrade head
.venv/bin/python scripts/import-hku-calendar.py --file private-data/calendar-imports/hku-calendar.ics --username 你的账号
```

省略账号时，仅在恰好一个活跃账号绑定过邮箱时自动选择，否则拒绝导入。命令仅打印条数和状态。刷新页面即可查看。

迁移降级会删除课程表，不应作为日常撤销导入的方式；数据库恢复单独评估，回滚代码不会自动恢复课程数据。

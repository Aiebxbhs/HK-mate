# 前端改版计划（2026-11-15 起）

> 目标：界面简洁、安静、好读，颜色只做点缀。风格参考与首页示意见 `docs/design/home-preview.html`（示意数据，用浏览器直接打开）。
> 做法：分阶段改，每个阶段单独可用、`bash scripts/check.sh` 全部通过、在浏览器里核对后，由用户确认再进入下一阶段。

## 设计约定

| 项 | 约定 |
|---|---|
| 底色 | 暖白 `#F3EFEA`；右上一团很淡的暖橙柔光，不用图片 |
| 文字 | 正文深灰 `#2A2724`（对比度 13.0）；次要文字 `#6B655F`（5.0）；不再使用更浅的灰字 |
| 点缀色 | 橙 `#F0894A`，只用于小圆点、进度条、柔光和数字徽标底色 `#FBE3D3`；不用于文字，不做大面积色块 |
| 面板 | 轻毛玻璃：白色 50% 透明 + 模糊，边框几乎不可见，圆角 26px；只给需要成组的内容用，列表行用细分隔线而不是卡片 |
| 字体 | 中文用系统字体（苹方等）；拉丁字母和数字用 Outfit（待确认，见“待确认事项”）；大标题用细体 |
| 字号 | 13 / 14 / 15 / 16 / 20 / 36 / 52px；正文 15–16px，最小 13px |
| 去掉 | 全大写英文小标题、标语式页脚、黑色大卡片、按钮后的装饰箭头、所有内容都套卡片 |
| 质量底线 | 手机 375px 可用、键盘焦点可见、遵守“减少动态效果”、文字对比度 ≥ 4.5（≥ 24px 的大字 ≥ 3） |

## 阶段

### 第 1 阶段：设计地基
- 在 `styles.css` 顶部建立设计变量（颜色、字号、圆角、玻璃面板），全局替换写死的颜色和过小字号。
- 换底色与柔光背景，加载字体。
- 删除全大写英文小标题（如 “A LITTLE SPACE, JUST FOR YOU”“ACCOUNT DETAILS”“PASSWORD”）和页脚标语。
- 页面结构暂不动，只换“皮肤”，所有页面立刻统一到新配色。

### 第 2 阶段：导航骨架
- 桌面端：顶部文字导航（今天 / 日程 / 课表 / 邮件 / 课堂翻译 / HKU 指南），当前项下方一个橙色小点；右侧头像菜单（我的账号、退出登录）。取代汉堡菜单和侧边抽屉。
- 手机端：底部轻玻璃标签栏（今天 / 日程 / 邮件 / 翻译 / 指南），课表从“日程”进入。
- 原来的子菜单改为页面内的二级切换：邮件（收件箱 / 起草邮件 / 邮箱管理）、日程（日程列表 / 添加日程）、课堂翻译（实时翻译 / 课程记录）、HKU 指南（3 类）。
- “邮件”旁显示新邮件数（未忽略的新邮件通知数，来自现有 `GET /api/v1/mail-notifications`，为 0 时不显示）。
- 保留现有地址（`#/inbox` 等）、浏览器前进后退和刷新后回到原页面的行为。

### 第 3 阶段：首页“今天”
- 只保留三样：问候语、日期（及教学周，见待确认事项）、AI 输入条（现有 AI 助手换样式，展开后仍是对话）。
- 下方“接下来 5 天”：按天列出课程、手动日程和截止事项（来自现有 `GET /api/v1/calendar/events`），截止事项用小圆点，最近的用橙色；空白日显示“没有安排”；“全部日程”进入日程页。
- 移除首页的新邮件通知和右上角“今日日程”下拉。

### 第 4 阶段：邮件区
- 新邮件通知（自动摘要、分类、查看原文、忽略、失败重试、加入日程）整体移到“邮件”区顶部。
- 忽略或处理后导航上的数字同步减少。

### 第 5 阶段：逐页改样式（每页单独确认）
1. 日程 2. 课表 3. 收件箱 / 起草邮件 / 邮箱管理 4. 实时翻译 5. 课程记录 6. HKU 指南 7. 我的账号 8. 登录与注册
- 统一页头：标题 + 一句用途 + 右侧主要操作；列表用分隔线；空状态给出下一步操作。

### 第 6 阶段：收尾
- 删除不再使用的样式和组件，检查对比度、键盘操作、手机宽度、减少动态效果。
- 更新 `AGENTS.md` 中首页与导航的描述，更新相关测试。

## 待确认事项
- **字体**：Outfit 为开源字体（SIL OFL）。建议把字体文件放进 `frontend/public/fonts/` 由本机提供，不从 Google 加载；属于新增资源，需确认。若不加，数字也用系统字体。
- **教学周“第 n 周”**：系统没有港大校历数据。可按已导入课表中最早一节课所在周推算，或暂不显示。
